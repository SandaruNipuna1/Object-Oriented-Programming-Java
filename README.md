# Object-Oriented Programming – Java Labs & Project

A collection of Java laboratory exercises and a practical application developed as part of the Object-Oriented Programming module during my BSc (Hons) in Information Technology at SLIIT.

This repository demonstrates fundamental Java programming concepts, object-oriented principles and their practical application through a Spring Boot-based student management system.

## Technologies Used

- **Programming Language:** Java
- **Framework:** Spring Boot
- **Web Technologies:** JSP, HTML
- **Build Tool:** Maven
- **Java Version:** 17
- **Development Environment:** IntelliJ IDEA

## Laboratory Exercises

The repository contains nine laboratory exercises covering Java programming and object-oriented concepts.

| Lab | Topics Covered |
|---|---|
| Lab 1 | Java fundamentals, calculations, arrays and pattern printing |
| Lab 2 | Conditional statements, arrays, loops and basic problem-solving |
| Lab 3 | Classes, objects, encapsulation, getters and setters |
| Lab 4 | Constructors, constructor overloading and object-oriented applications |
| Lab 5 | Constructors and practical object-oriented programming exercises |
| Lab 6 | Classes, inheritance and polymorphism-related exercises |
| Lab 7 | Inheritance and object relationships |
| Lab 8 | Object relationships, composition and application development |
| Lab 9 | Abstract classes, interfaces and polymorphism |

## Project: Driving School Registration and Scheduling System

The project includes a Spring Boot-based student management application developed as part of a broader driving school system.

### Implemented Functionality

- Create student records
- View student details
- Update existing student information
- Delete student records
- Manage student data through a web interface

### Technical Implementation

- Spring Boot for backend application development
- Java 17
- Spring MVC architecture
- Controller, Service and Repository layers
- Java Server Pages (JSP) for the user interface
- JSON file-based student data storage
- Maven for dependency management and project building

## Learning Outcomes

Through these laboratory exercises and the project, I gained practical experience in:

- Applying object-oriented programming principles.
- Designing and implementing Java classes and objects.
- Understanding encapsulation, inheritance and polymorphism.
- Working with abstract classes and interfaces.
- Developing modular Java applications.
- Implementing CRUD operations.
- Understanding layered application architecture.
- Building web applications using Spring Boot.
